# Halo IP 流量监控 1.1.0 服务器测试包

作者：0rion

## 安装/升级

1. Halo 版本保持在 2.25.0 或更高的 2.25.x。
2. Console -> 插件 -> 安装插件，上传 `halo-plugin-traffic-monitor-1.1.0.jar`。
3. 从旧版升级时直接上传新版 JAR，启用后刷新 Console。
4. 进入插件设置，先把管理端出口 IP 或管理网段填入“IP 白名单”。
5. 使用 Nginx/CDN 时，在代理正确覆盖客户端 IP 请求头后再开启“信任反向代理 IP 请求头”。

## 默认防护

- 白名单：127.0.0.1、::1，支持 IPv4/IPv6 CIDR。
- 同一 IP 10 分钟内登录失败 5 次：自动封禁 1440 分钟。
- Console 的 IP 排名可手动封禁 24 小时，封禁列表可立即解封。
- 被封禁请求返回 HTTP 403、`X-Traffic-Monitor-Blocked: true` 和 `Retry-After`。
- 统计、告警和封禁状态保存在进程内；Halo/插件重启后封禁状态清空，白名单和阈值配置保留。
- 访问统计和告警保留 7 天并自动清理。

## 回滚

停用 1.1.0，重新上传并启用之前保留的 1.0.1 JAR。
