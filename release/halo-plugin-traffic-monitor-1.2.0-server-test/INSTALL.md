# Halo IP 流量监控 1.2.0 服务器测试包

作者：0rion

## 安装/升级

1. Halo 保持在 2.25.0 或更高的 2.25.x。
2. Console -> 插件 -> 安装插件，上传 `halo-plugin-traffic-monitor-1.2.0.jar`。
3. 进入插件设置，先把管理端出口 IP 或管理网段加入白名单。
4. 使用 Nginx/CDN 时，确认代理覆盖客户端 IP 请求头后开启“信任反向代理 IP 请求头”。

## 本版新增

- 柱状图按来源 IP 堆叠，点击时间柱查看每个 IP 的访问次数。
- 按 IP、路径、状态码和时间范围筛选请求明细。
- 查看响应状态、响应头和文本响应正文；默认单条正文最多 32 KiB。
- 敏感响应头自动显示为 `[REDACTED]`。
- 异常流量告警命中后自动封禁来源 IP 24 小时。
- 点击告警“确认并封禁 24h”会确认告警并封禁对应 IP。
- 手动封禁支持 24 小时、7 天、30 天和永久模式。
- 白名单支持单个 IPv4/IPv6 与 CIDR，始终优先放行。
- 访问统计、告警和请求明细保留 7 天；请求明细默认最多 2,000 条。

## 状态说明

统计、请求明细和封禁状态保存在进程内，Halo 或插件重启后从空状态开始；白名单与阈值配置由 Halo 保存。

## 回滚

停用 1.2.0，重新上传并启用之前保留的 1.1.0 JAR。
