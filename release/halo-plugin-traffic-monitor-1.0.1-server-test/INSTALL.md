# Halo IP 流量监控 1.0.1

## 本版更新

- 访问时序、IP 统计和异常告警固定保留 7 天。
- 超过 7 天的数据由新请求和仪表盘读取自动触发清理，最多延迟 1 分钟。
- 更换为霓虹雷达、流量脉冲与安全盾组合的新 Logo。

## 兼容性

- Halo: `>= 2.25.0`
- 运行时验证版本：`2.25.4`

## 安装/升级

1. 先备份 Halo 数据库和工作目录。
2. Halo Console -> 插件。
3. 新安装：上传 `halo-plugin-traffic-monitor-1.0.1.jar`。
4. 已有 1.0.0：在插件详情中选择升级，上传同一 JAR。
5. 启用一次后等待启动完成，避免连续切换开关。
6. 从左侧“安全 -> IP 流量监控”进入。

## 校验

```bash
sha256sum -c halo-plugin-traffic-monitor-1.0.1.jar.sha256
```

## 说明

- 统计的是进入 Halo 的 HTTP request/response body 字节。
- 当前版本使用进程内数据；Halo 重启或插件重载后从新的统计窗口开始。
